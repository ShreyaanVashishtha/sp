# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

The JamRoom project takes security and user privacy seriously. If you discover a potential security vulnerability, please do not disclose it publicly via GitHub issues or discussions.

Instead, please report the vulnerability privately by:
1. Opening a private [GitHub Security Advisory](https://github.com/) in the repository settings, or
2. Contacting the project maintainer directly via GitHub profile details.

### What to include in your report:
- A clear description of the vulnerability.
- Steps to reproduce the issue or a proof-of-concept (PoC).
- Any potential impact on users or infrastructure.

We will acknowledge receipt of your report within 48 hours and work on a fix promptly.
